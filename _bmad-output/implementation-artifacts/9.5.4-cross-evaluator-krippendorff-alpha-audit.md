### Krippendorff α ordinal invariants (per Story 9-7 shipped code)

Per `benchmark/agreement.py:1-51`, α computation invariants (verified in Story 9-7 CR pass, 100% applied-rate):

- α ∈ [-1.0, 1.0]. α=1.0 = perfect agreement; α=0.0 = chance (no signal); α<0 = systematic disagreement (worse than chance).
- All raters agree perfectly → α=1.0.
- All ratings identical across raters + units (no variability) → α=1.0 (trivially perfect).
- Missing data (`None` entries) → unit treated as unpairable for that rater (Krippendorff's principle).
- Fewer than 2 raters → `ValueError`.
- Zero-pairs after alignment (`try/except ValueError → alpha = -1.0` sentinel per `anchor_stability_audit.py:337-344`) → treated as untrusted, triggers FAILED-CALIBRATION path.

**Verdict bands (per `anchor_stability_audit.py:85-100` `_classify_alpha`):**
- α ≥ 0.8 → `trusted`
- 0.6 ≤ α < 0.8 → `uncertain`
- α < 0.6 → `untrusted`

### Zero-pairs sentinel — how to distinguish it from real α

Post-walk, if the CLI reports α = -1.0000, distinguish two very different outcomes:

1. **Zero-pairs dispatch failure:** the `_audit_all_tasks` function fell through to the empty-list branch at `anchor_stability_audit.py:331-335` because `_compose_per_anchor_scores` returned an empty list for every task. Root cause: every dispatch on at least one evaluator returned None (rate-limit / provider-error / schema-rejection). CLI prints the specific "ZERO anchors were paired by both evaluators" error to stderr. Exit code 2, but NO baseline file written (per CR-F1 zero-pairs guard at `anchor_stability_audit.py:486-498`).

2. **Genuine α = -1.0 computation:** the audit successfully paired ≥ 1 anchor on both evaluators, computed α, and the result mathematically evaluated to -1.0 (indicating systematic max disagreement — e.g., primary consistently scored 5 where secondary scored 1). CLI prints the normal untrusted-shape output ("Wrote FAILED-CALIBRATION payload to ..."). Exit code 2, FAILED-CALIBRATION file DOES exist with `krippendorff_alpha=-1.0` in the JSON.

**How to tell which:** check for FAILED-CALIBRATION file existence + read `n_anchors_paired` field. If file exists AND `n_anchors_paired > 0` → genuine α=-1.0. If file does not exist → zero-pairs dispatch failure; re-run needed after `router_calls` triage.
