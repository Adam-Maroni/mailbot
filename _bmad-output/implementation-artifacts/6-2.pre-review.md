## 3. Adversarial self-review

- **[HIGH]** `mailbot_api/main.py:_admin_pause` calls `state.pause(db_path, reason=request.reason)` directly — NOT through `verbs/router_control.pause_router`. The state mutation IS identical (verb just wraps the same call), but if Story 5-6's MCP `/pause` slash command and Story 6-2's `/admin/pause` HTTP endpoint diverge in side-effects later (e.g., add audit logging in the verb but not in the admin endpoint, or vice versa), the two paths could drift. A reviewer may suggest factoring a shared internal helper. Trade-off: avoiding the verbs-import boundary boundary is the explicit architectural decision per Dev Notes; the duplication is small (10 lines of state.pause + response-dict construction).
- **[HIGH]** `mailbot_api/main.py:_admin_resume` has the same pattern as `_admin_pause` — calls `state.resume(db_path)` directly. Same trade-off + same disposition.
- **[MEDIUM]** `scripts/mailbot.py:_cmd_logs` uses `subprocess.Popen` with `text=True` + `bufsize=1` (line-buffered). On Windows the line-buffered text mode can have CRLF issues — `line.rstrip("\n")` would leave a trailing `\r`. Acceptable: `_filter_log_line` parses JSON which tolerates trailing whitespace; non-JSON pass-through preserves the `\r` (Windows console renders fine). Edge case only matters if the operator pipes output to a `\n`-strict parser downstream.
- **[MEDIUM]** `_filter_log_line`'s `parsed.get(field)` doesn't recurse into nested JSON. If the structured log shape ever nests `event` under a parent key (e.g., `{"context": {"event": "..."}}`), the filter wouldn't match. Acceptable: Story 1-4's logging shape is flat; nested-event support is YAGNI.
- **[MEDIUM]** `_cmd_pause` / `_cmd_resume` use 10s `httpx.Client` timeout. Same 10s budget as Story 6-1's `_cmd_status`. Acceptable.
- **[MEDIUM]** `_PauseRequest` defaults `reason` to `"manual cli pause"`. If a caller POSTs `{}` to `/admin/pause`, Pydantic populates the default. Mirrors the CLI default. Acceptable.
- **[MEDIUM]** `_cmd_logs` returns 0 on KeyboardInterrupt during follow mode. Some operators expect Ctrl-C to exit with 130 (SIGINT convention). Decision: exit 0 because the operator's intent was "stop tailing", not "abort with error". A reviewer may prefer 130; trade-off is bash-script ergonomics.
- **[LOW]** `mypy --strict scripts/mailbot.py` isn't in CI by default (project gate is `mypy --strict mailbot_api/`). The 5 pre-existing errors that this story fixed were only surfaced by my targeted manual run. A reviewer may suggest extending the CI gate to scan `scripts/` too. Trade-off: `scripts/` has more dynamic patterns (argparse Namespace, subprocess, etc.) that mypy is noisier about; deliberate scope choice. Documented in Completion Notes.
- **[LOW]** `_render_status_report` ROUTER section uses `bool(router.get("paused"))` — same `_as_dict` defensive guard pattern as other sections. Consistent.
- **[INFO]** The `subprocess.Popen` has `noqa: S603` (untrusted-input bandit). The argv is fully constructed from constants + validated int (`tail`), so no shell injection surface. Acceptable.
