Verdict: PASS

Models pulled successfully into the `mailbot_ollama` named volume:
  * qwen2.5:3b-instruct-q4_K_M — 1.9 GB
  * nomic-embed-text:latest — 274 MB

The `docker compose down` will REMOVE the containers but PRESERVE the named
volume (since `down` doesn't pass `-v`), so subsequent stack stand-ups will
have the models already present and the warmup will exit immediately (idempotent
pull is no-op on already-present model).

Note: the warmup container takes ~60-90s on a typical home connection
(observed 28-32 MB/s during pull). Operators should NOT run `ollama list`
immediately after `docker compose up -d` — wait for the warmup container to
exit (or `docker logs -f mailbot-ollama-warmup` to print `model warmup
complete`) before verifying.
