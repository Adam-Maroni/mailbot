## Section 3 — Verdict interpretation

**Band: α = 0.3490 < 0.6 → `untrusted`** (thresholds per `anchor_stability_audit.py:85-86`: trusted ≥ 0.8, uncertain ≥ 0.6). α ∈ [-1, 1] invariant holds. This is a **genuine measurement** (n_anchors_paired = 40 > 0, FAILED-CALIBRATION file exists), NOT the zero-pairs sentinel — the run 1 vs run 2 contrast in this document is itself the demonstration of the two shapes.

**Structure of the disagreement (from the table + anchor-file cross-read):**

1. 29/40 anchors (72.5%) in PERFECT agreement (delta=0). draft_reply is near-unanimous: 19/20 perfect.
2. The disagreement is concentrated and systematic: **haiku scores summary_short on a compressed 2–3 scale** — it never rated any summary_short anchor above 3, so every anchor where opus said 4 or 5 produced a delta of 2–3. → **Finding F4**.
3. **The α measurement itself is confounded (Finding F3, the load-bearing one):** `build_anchors_block` (`benchmark/scoring/subjective.py:140-162`) renders ALL 20 anchors — each WITH Adam's per-axis scores, `adam_overall_score`, and rationale — and `_run_anchor_calibration` sends that full block with every dispatch, **including the dispatch that scores an anchor contained in the block**. The evaluator is handed the answer key for the item under test. Evidence it matters: Adam's anchor labels follow a perfect 2,3,4,5,2,3,4,5… cycle in file order (both tasks — verified by direct read of both jsonl files), and opus reproduced that cycle 39/40 (sole deviation: summary_short-016, opus 1 vs Adam 5). Opus's near-perfect "calibration" is at least partly answer-key lookup; haiku's summary_short ceiling shows it ignores the key there. **α=0.3490 therefore measures "propensity to use the visible answer key" as much as genuine scoring agreement — a Path A re-run without fixing the leak re-measures the same confound.**

**What each band would have meant for Story 9.5.5 (for the record):** trusted → unblock high-confidence; uncertain → unblock with caveat; **untrusted (actual) → Story 9.5.5 waits for Path A re-run OR Path B accept-with-rationale.**
