## 3. Adversarial self-review

- [LOW] Position semantics: the `position` field on `RedactionMatch` indexes into the ORIGINAL text for the FIRST pattern's matches, but for later patterns it indexes into the PARTIALLY-REDACTED text (each pattern's `match.start()` is computed against the current state of `current`). Documented inline as accepted imprecision; the forensic linker is the `prefix` field on the log line, which is always the matched chars (regardless of original-vs-redacted ambiguity).
- [LOW] The Bearer pattern includes `=` (base64 padding) but the OpenAI key + Anthropic key patterns do NOT include `=`. If an LLM-issued key ever uses `=` padding, it would be partially matched. Not a real risk per current API contracts.
- [LOW] `S105` was suppressed inline on the BEARER_TOKEN enum value. This is a ruff bandit-style false positive; the StrEnum value is a kind LABEL, not a secret.
