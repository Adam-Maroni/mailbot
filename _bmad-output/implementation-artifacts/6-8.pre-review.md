The §5.12 rule fires at 3+ criteria. 3 hit (1 + 2 + 4-partial). Even discounting #4 to half, the (1 + 2) pair on a NEW agent-facing surface that puts text on Adam's Discord screen is sufficient on its own — the operator-facing-with-new-code combination is exactly the pattern §5.12 wants caught at this gate.

Notable structural risk surfaces a fresh reviewer should grade adversarially:

1. **Window-math correctness (Test 5).** `today` = UTC midnight; `week` = rolling 7 days; `month` = first-of-month UTC midnight. Off-by-one between "today since 00:00:00Z" vs "last 24h" was called out in story Dev Notes as the highest-bug-density part. Tests pass on current clock, but reviewer should probe for clock-skew + DST edges (Python `datetime.now(timezone.utc)` is DST-immune; sanity-check the `_period_window_start` math against a frozen clock).
2. **`plt.close(fig)` in `finally:` (memory hygiene).** Long-running worker process can leak Figure instances; Test 9 patches `plt.close` and asserts ≥1 invocation. Reviewer should confirm both `_render_empty_png` and `_render_bar_chart_png` paths have `try/finally` wrapping (they do — but the symmetry between the two helpers is worth a re-check).
3. **Boundary-check completeness.** `_MATPLOTLIB_PYPLOT_ALLOW` is locked to a single file (`render_spend_chart.py`). The `__init__.py` re-export does NOT need pyplot, only `matplotlib.use("Agg")` lives in the verb file. Reviewer should verify the `ast.Import` + `ast.ImportFrom` branches BOTH catch `matplotlib.pyplot` (they do), and that a JoinedStr/f-string bypass is N/A here (no SQL-style construction risk for an import statement).
4. **Default-arg consistency with Story 5-6 CR-1.** MCP wrapper defaults `period="month"` so `/spend` (no arg) works end-to-end. Story 5-6 CR-1 fixed the same class of bug for `/cost`. Reviewer should confirm the default is the most useful one (Adam asked for the monthly view in the AC's "User: `/spend month`" narrative).
5. **F6 carve-out documented but not patched.** End-to-end Hermes-dispatch round-trip is deferred to Phase 3.5. The carve-out is documented in the integration-test docstring, the story Completion Notes, the SKILL.md turn structure, and the closure-gate annotation. Reviewer should confirm the scope discipline (no half-finished Hermes-side code was sketched-and-deferred).
6. **SKILL.md narration drift.** The previous "Other internal verbs that are also NOT MCP-exposed" passage was stale (cost/pause/resume/reset_degraded_mode WERE registered in Story 5-6). The fix reworded it AND added a new MCP-exposed section. Reviewer should grade whether the reworded narrative is internally consistent (no dangling references to "Story 5-6 wires them up alongside the slash-command dispatcher" implying the dispatcher hasn't shipped, which is the schema-reality correction's whole point).
