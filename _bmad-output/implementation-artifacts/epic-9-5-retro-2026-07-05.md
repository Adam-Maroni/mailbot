## 4. What was hard — systemic findings (no blame)

1. **Cost-truth infrastructure is broken, and was left broken.** F-PLACEHOLDER-3X-DRIFT (pricing placeholders ~2.7× overstated) + F-UNKNOWN-MODEL-COST-GATE (unregistered model → $0 estimate → false-safe `--yes`) — both P0, both filed in 9.5.3, both knowingly carried unfixed through 9.5.4 (which filed a third: F-COST-ESTIMATE-AGGREGATE-MASK). Consequences: the $36-vs-$13.46 trust-failure event, a $0.00 pre-flight before a real opus scorer run, +$3.43 overshoot vs authorization. **Every dollar gate in the codebase (Layer-4 $0.20/call, pre-flight, $30 monthly cap) is currently miscalibrated ~3×.** Mitigation is manual: Adam-read Console (the Admin cost_report API is structurally unavailable on a solo Console org — workload key 401s, admin-keys page 404s).
2. **Story-spec-vs-shipped-code drift.** 9.5.3's spec named CLI shapes that don't exist (`--tasks all --models policy-default`, `--scorer-model`); 9.5.4's spec named an unregistered secondary model (sonnet-4-5 → 40 dead dispatches, Run 1 wasted) and an unsatisfiable byte-identical acceptance criterion. Walk specs were authored against assumed code, not the shipped CLI/model registry.
3. **"No-code walk story" is a fiction.** All three walk stories shipped production code (9.5.2: Path B bridges; 9.5.3: three P0/P1 hotfixes; 9.5.4: leak fix). The CR-cadence assumption "walks produce no code → CR skipped" was rescued each time by escalation, but the default was wrong every time.
4. **Reviewer-model discipline eroded into retroactive blessings.** Same-family reviewer in 9.5.3's escalated CR; sonnet-5-for-sonnet-4-6 substitution in 9.5.4/9.5.5; same-family post-commit CR in 9.5.4 — each blessed after the fact (D2). No incident resulted, but the rule now exists mostly as exceptions.
5. **Checkbox/reality drift.** 9.5.3 marked Task 7 and AC-7 `[x]` when neither had executed; corrected only by later CR passes. Under walk pressure, story checklists drifted from ground truth.
6. **Run-mode bindings needed 6 halts to hold.** The binding markers were iteratively hardened (story banner + sprint-status marker + explicit dev-story naming) across 9.5.1–9.5.4 halts. The double-encoding now works — the 9.5.5 autonomous run respected scope cleanly — but the hardening was reactive.

## 5. Key insights

1. **L3 is where the truth lives.** Epic 9 closed at L2 "clean" with a benchmark instrument that had never measured anything real; Epic 9.5's walks then found a 3-day production outage, a measurement-invalidating leak, and an evaluator that can't agree with itself. The L1/L2/L3 framework (Epic 9 retro B3) is validated — and the corollary is now on record: **budget walk stories as code-shipping stories.**
2. **Honest failure + signed rationale beats engineered success.** α stayed 0.3490; the baseline file keeps FAILED-CALIBRATION in its name; policy.yaml v1 changed nothing and says why. Three signed rationales now form the v1 evidence posture: single-evaluator-trusted (opus-only), α ≥ 0.6 and canonical `v1.json` as v2 gates, benchmark comparison INSUFFICIENT_DATA.
3. **Cost gates are safety equipment, not accounting.** The pre-flight gate printing $0.00 before a real-dollar dispatch is functionally a disabled seatbelt. Cost-truth repair belongs *before* the next real-spend walk, not alongside it.
